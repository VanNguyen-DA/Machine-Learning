#### Project Description:
This project using the data from SKU sales of factory. The purpose is forecasting the daily sales of top 10 SKU that contributed most to the revenue of the company. (pareto principle)

#### Repo structure: 
````
├── data/                 # Dataset files
├── notebooks/            # Jupyter notebooks for analysis and modeling
├── src/                  # Source code modules
│   └── utils/            # Utility scripts and plotting functions
├── forecast_env/         # Virtual environment
├── models/               # Saved trained model and model artifacts
├── .gitignore
└── .dvcignore
